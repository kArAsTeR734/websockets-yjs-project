# Collaborative Note

Небольшой веб-редактор для совместной работы над заметкой в реальном времени. Приложение построено на React, TypeScript и Tiptap, синхронизирует изменения через Yjs и WebSocket-сервер Hocuspocus, показывает статус подключения и список активных пользователей. Локальная копия заметки сохраняется в IndexedDB браузера.

## Запуск

Понадобится Node.js 20.19+ и npm.

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите WebSocket-сервер в первом терминале:

   ```bash
   npm run server
   ```

3. Запустите клиент во втором терминале:

   ```bash
   npm run dev
   ```

4. Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`). Для проверки совместного редактирования откройте страницу в нескольких вкладках.

По умолчанию сервер работает на `ws://127.0.0.1:1234`. Адрес можно изменить через переменную `VITE_HOCUSPOCUS_URL`, а порт сервера — через `PORT`.
